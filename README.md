# IDX Exchange — SQL Portfolio

SQL analysis of 40,000+ real estate MLS listings using MySQL and DBeaver.

## What I Analyzed
- Pricing trends across California cities
- Open house activity patterns by city and day of week
- Historical sold vs. active listing price comparisons
- Advanced SQL analytics using CTEs and window functions
- Market competitiveness and buyer opportunity analysis

## Key Findings
- Sacramento showed strong seller conditions with homes selling slightly above asking price on average
- Saturday was the most active open house day across multiple cities
- Several high-demand cities had significantly higher price-per-square-foot trends compared to surrounding markets
- Active listing prices were generally higher than historical sold prices, suggesting continued market competitiveness
